You can run community bingo's using the [[/bingo]] command, and the bot will automatically handle all of it for you.

## Notes

- Ironmen can join bingos for free. They cannot be given GP prizes, or create bingos.
- Upon the bingo finishing, the creator of the bingo needs to do [[/bingo finalize]] to receive the GP pool. The creator of the bingo is responsible for handing out the GP, based on whatever split you have decided. You do not need to finalize the bingo on time, the bingo will automatically finish at the exact second it needs to, the finalize command just does some final things, and hands out the gp.
- A person can participate in several bingos at once.
- Bingos are private to the server they were made in. In other words, you can only join it from that server. Global bingos are limited to the official bingos. However, for any bingo, the commands/trips the players do (to get loot) can be done anywhere.

## Creating a Bingo

To create a bingo, you need to input the following things:

- Title
- Duration in days(7 = 7 days)
- Start Date unix seconds. Use [https://hammertime.cyou/?tz=Etc%2FGMT](https://hammertime.cyou/?tz=Etc%2FGMT) to find this number. It's the last in the list, and is just a plain number that looks like this: `1695859800`. This indicates the exact time at which your bingo starts.
- Ticket price: The ticket price per person. Each player agrees to pay when joining a team lobby. Non-ironmen are charged when the creator finalises the full roster. If the team disbands before the bingo starts, paid tickets are refunded.
- Team size: Size of the teams.
- Organisers: people who are allowed to manage the bingo, including replacing the tile configuration before the start.

You can also select a seasonal `theme` and upload a JSON `configuration` containing 28 tiles. Without a configuration, the bingo uses the starter 28-tile board.

## Joining a Team

Use `/bingo make_team` to create a persistent team lobby. Optional player selections invite those players; they still need to join themselves. The quick-join button lasts 30 seconds and does not keep the creator or joiners busy. Afterwards, players can use `/bingo join bingo:<bingo ID> team:<team ID>`. Use `/bingo view` to find lobby IDs.

Players can join until the maximum team size is reached or the creator finalises the roster. Registration always closes when the bingo starts. Private bingos require players to join from the bingo's server. The `same_server_only` option defaults to true and also restricts global bingo teams to the server where their lobby was created; setting it to false only permits joins from other servers for global bingos.

The team creator must use `/bingo manage_team finalize_players:true` before the bingo starts. The team must have exactly the configured number of players. Everyone's eligibility and GP are checked again, and all tickets are charged together. If a player can no longer afford a ticket or is blacklisted, nobody is charged and the creator can change the roster. Unfinished lobbies do not score, enter the leaderboard or contribute to the prize pool.

Before finalising, the creator can use `/bingo kick` to remove a player and prevent them rejoining that lobby. Players can use `/bingo leave_team` to leave an unfinished lobby individually. The creator can cancel with `/bingo manage_team cancel:true`; unfinished lobbies can also be cancelled after registration closes and never cost any GP.

Once a roster is finalised, players cannot join or be kicked. Before the bingo starts, cancelling or leaving a finalised team disbands it and refunds paid tickets, so everyone can form a new team. Existing teams retain this behaviour. Team finalisation is separate from `/bingo manage_bingo finalize:true`, which ends the event and pays its prize pool to the event creator.

## Managing your Bingo

Use `/bingo manage_bingo` to upload a replacement tile configuration, select seasonal artwork, add extra GP to the prize pool and manage rewards.

### Changing Tiles

Before the bingo starts, upload a complete JSON file using the `configuration` option. The file must contain exactly 28 tiles and replaces the existing tile list in board order.

Use `template:true` in `/bingo manage_bingo` to download the current 28-tile configuration or a starter template. Any player can use `/bingo view json:true` to check the current tile requirements. Tile configurations cannot be changed after the bingo starts.
